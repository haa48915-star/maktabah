# مكتبة رقمية متعددة اللغات

صفحة HTML ثابتة وتجريبية لعرض روابط الكتب حسب اللغة. لا تستخدم قاعدة بيانات أو خادمًا خلفيًا، وتعمل مباشرة عبر GitHub Pages.

## التشغيل محليًا

افتح `index.html` في المتصفح، أو شغّل أي خادم ملفات ثابتة.

## النشر

يتم النشر تلقائيًا عبر GitHub Pages عند الدفع إلى فرع `main`.
